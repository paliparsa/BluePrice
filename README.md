# BlueGate - لندینگ پیج سایبر گلاسمورفیسم و پنل ادمین فروش VPN 🚀

یک لندینگ پیج فوق‌العاده مدرن، سریع و استاتیک با **طراحی اختصاصی Cyber-Glassmorphism** جهت ارائه و فروش پکیج‌های اینترنت و VPN. این پروژه دارای ۳ پلن اختصاصی (Standard، Pro، Emergency)، محاسبه‌گر آنلاین، سیستم صدور فاکتور فوری و پیش‌فاکتور تلگرام، پنل مدیریت پیشرفته با پیش‌نمایش در لحظه و پشتیبانی کامل از GitHub Pages است!

---

## ✨ ویژگی‌های جدید و برجسته redesign

- 💎 **طراحی نئونی Cyber-Glassmorphism:** رابط کاربری تماشایی با افکت‌های گلاسمورفیسم، نورپردازی‌های محیطی، لوگوی سه‌بعدی و تایپوگرافی Vazirmatn.
- 📦 **۳ پلن با ساختار متناسب نیاز کاربران:**
  - **BlueGate Standard (🟢):** مولتی لوکیشن با پرچم کشورهای انگلستان 🇬🇧، سوئد 🇸🇪، ترکیه 🇹🇷 و پینگ زنده. دارای گزینه‌های حجمی و پلن‌های نامحدود.
  - **BlueGate Pro (🟣):** ریبون محبوب‌ترین، آی‌پی ثابت اختصاصی، فیچرهای اختصاصی ترید و صرافی.
  - **BlueGate Emergency (🔵):** ضداختلال و مقاومت حداکثری در زمان قطعی سراسری اینترنت.
- 🧾 **صدور فاکتور رسمی و اتصال ۱-کلیکه به تلگرام:** انتخاب هر پلن فوری فاکتور رسمی همراه با کد پیگیری اختصاصی (`#BG-XXXXX`)، تاریخ دقیق، مبلغ و تضمین بازگشت وجه ایجاد نموده و متن پیش‌فرض را جهت ارسال به پشتیبانی تلگرام (`@BlueGateSupport`) آماده می‌کند.
- 🧮 **محاسبه‌گر آنلاین قیمت:** ابزار تعاملی اسلایدر تعیین حجم و محاسبه خودکار هزینه پلن‌ها به تومان.
- 🎟️ **سیستم کدهای تخفیف:** ورودی اعمال کد تخفیف در فاکتور رسمی با محاسبه آنی درصد تخفیف روی مبلغ پرداختی.
- ⚙️ **پیکربندی داینامیک (`config.json`):** قابلیت ویرایش کامل عنوان، توضیحات، قیمت‌ها، تخفیف‌ها، بنر اطلاعیه، تایمر معکوس، راهنمای اتصال و سوالات متداول.
- 🔐 **پنل ادمین اختصاصی (`_p8x2k4m`):** ویرایش زنده محتوا همراه با پیش‌نمایش در لحظه (Live Preview via `postMessage`)، پشتیبانی از رمزمستقیم و تایید دو مرحله‌ای (2FA).
- 🌓 **تم تاریک و روشن (Dark / Light):** سوئیچ روان بین تم سایبر تاریک و تم روشن با ذخیره‌سازی در LocalStorage.
- 📱 **اپلیکیشن وب (PWA):** همراه با Service Worker جهت کش آفلاین و قابلیت نصب روی گوشی و دسکتاپ.

## 📂 ساختار فایل‌های پروژه

- `index.html`: پوسته اصلی و ساختار لندینگ پیج
- `styles.css`: سیستم دیزاین کامل سایبر گلاسمورفیسم
- `app.js`: کنترلر تعاملی، محاسبه‌گر، فاکتور، تایمر و سینک با ادمین
- `config.json`: فایل دیتابیس داده‌های سایت
- `assets/`: تصاویر لوگو و باکس هدیه سه‌بعدی
- `_p8x2k4m/index.html`: پنل مدیریت ادمین

## 🚀 نحوه انتشار روی GitHub Pages

### روش اول: آپلود دستی (Drag & Drop)
1. وارد ریپازیتوری خود در GitHub شوید.
2. روی **Add file** -> **Upload files** کلیک کنید.
3. فایل‌های `index.html` `styles.css` `app.js` `config.json` و پوشه‌های `assets` و `_p8x2k4m` را کشیده و رها کنید.
4. روی **Commit changes** کلیک کنید.

### روش دوم: آپلود با گیت (Git Command Line)
```bash
git add .
git commit -m "Deploy BlueGate Cyber Redesign"
git push origin main
```
